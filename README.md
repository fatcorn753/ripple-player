# 波紋プレーヤー

手元の音楽ファイルを再生すると、中央の CD から曲に合わせて波紋が広がり、水面が揺れるプレーヤー。

## 使い方

https://fatcorn753.github.io/ripple-player/ を開くか、`index.html` をブラウザ(Chrome / Safari / Edge の最新版)で開き、音楽ファイルを選ぶか画面にドロップする。
ファイルは端末の外へ送らない。

| 操作 | キー |
|---|---|
| 再生・一時停止 | Space |
| 5 秒戻る・進む | ← / → |
| 前の曲・次の曲 | P / N |
| ファイルを開く | O |
| 水面と花火の切り替え | M |

水面をクリックやドラッグすると、その場所にも波が立つ。

### 花火

操作バーの花火のボタン(または M キー)で、夜の湖で花火が上がる画面に切り替わる。選んだ画面は次に開いたときも残る。

- ファイルの曲は、読み込んだときにテンポと拍の並びを先に調べておき、打ち上げてからちょうど拍の瞬間に開くようにする
- 盛り上がるほど打つ拍が増える: 静かな所は小節の頭だけ、中くらいは 2 拍ごと、山場は毎拍と裏拍のスターマイン。小節の頭は大きく、ほかの拍は小さく、8 小節ごとや急に盛り上がった所では大きな花火を 3 発並べる
- 種類は牡丹・菊・柳・冠・輪・点滅・ダリア・ヤシ・分裂・千輪・土星とスターマイン。静かな所は寒色、盛り上がると暖色
- タブやマイクの音は先が分からないので、拍を聞いてからすぐに開く
- 空をクリックするとそこに花火が上がり、湖をクリックすると波紋が立つ

### YouTube や Spotify の音に合わせる

ファイルを選ばなくても、ほかで流している音に合わせて波を出せる。

- **パソコン(Chrome / Edge)**: 「ほかのタブの音を使う」を押し、共有の画面で YouTube などのタブを選んで「タブの音声も共有する」をオンにする。ブラウザの「共有を停止」か、再生ボタンで止まる。
- **スマホ**: 「マイクで音を拾う」を押し、ほかのアプリで流している音をマイクで拾う。周りの音も拾うので、反応はタブより鈍い。

YouTube の埋め込みや Spotify の再生 SDK は、音の中身をページから読めない(別サイトの枠・DRM)ため、ブラウザの共有とマイクを使っている。受け取った音は解析だけに使い、保存も送信もしない。

## 仕組み

- `water.js`: WebGL2 で高さ場の波動方程式を解き、コースティクス → 水面と CD → ブルームの順に多段で描く。遅い端末では自動で画質を下げる
- `audio.js`: Web Audio API で帯域ごとの音量と、低音の立ち上がり(拍)を検出する。ファイルのほか、タブやマイクの音も解析できる
- `fireworks.js`: 花火の粒子(JS で計算し、動いた向きに伸ばした光として描く)と、夜空・湖面の映り込み。湖の波とブルームは `water.js` のシェーダーを使い回す
- `beatmap.js`: 曲全体を先に解析し、テンポ・拍の並び(自己相関と動的計画法)・小節の頭・盛り上がりの推移を求める(花火を拍の前に打ち上げるため)
- `app.js`: 再生リスト・操作・音から波や花火への変換
- `tokens.css` `base.css` `components.css`: fatcorn753-design からのコピー(編集しない)
